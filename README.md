Web Application Security Assignments

This repository contains my practical assignments and reports completed during the Web Application Security training at ICDFA.

The assignments focus on identifying and understanding common web application vulnerabilities and how attackers exploit them. Each folder contains detailed reports, screenshots, and analysis of the vulnerabilities discovered during the labs.

Topics Covered:
- SQL Injection
- Cross-Site Scripting (XSS)
- Authentication and Session Management Vulnerabilities
- Web Application Enumeration
- Input Validation Issues
- OWASP Top 10 Security Risks

Tools Used
The following tools were used during the practical exercises:
- Burp Suite
- Web browsers developer tools
- Kali Linux
- DVWA
- Foxy Proxy
- Metasploitable


Repository Structure

Each file represents a different lab or assignment topic and contains the relevant PDF reports and supporting materials.


Purpose
The goal of these assignments was to build hands-on experience in identifying and analyzing common web application vulnerabilities and to strengthen practical cybersecurity skills.
